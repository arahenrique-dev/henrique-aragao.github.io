# Henrique Aragão — Creative Developer

Interactive 3D portfolio built with **Three.js**, **WebGL**, and **JavaScript**.

The portfolio is designed as an interactive 3D workspace, combining my interests in **creative development, visual arts, music, design, and storytelling**.

### Tech

* JavaScript
* Three.js / WebGL
* Vite
* Blender
* HTML / CSS
* GSAP

### Features

* Interactive 3D environment
* Clickable objects and camera transitions
* 3D models and animations
* Interactive pinboard and paintings
* Music player
* Responsive interface
* CV, LinkedIn and GitHub access

### Run locally

```bash
npm install
npm run dev
```

Then open the local URL provided by Vite.
